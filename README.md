# 🖼️ Image Gallery

A responsive and interactive Image Gallery built using **HTML, CSS, and JavaScript**. This project allows users to browse images through an elegant gallery layout, view images in a lightbox, navigate between images, and filter images by category.

## 🚀 Features

### Core Features

* 🖼️ Responsive Image Gallery Layout
* 🔍 Lightbox View for Enlarged Images
* ⏮️ Previous Image Navigation
* ⏭️ Next Image Navigation
* ✨ Hover Effects on Images
* 🎨 Smooth Transitions and Animations
* 📱 Fully Responsive Design

### Bonus Features

* 🏷️ Image Categories and Filters
* ⚡ Dynamic Image Navigation
* 🎯 User-Friendly Interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## ✅ Task Requirements Implemented

* Design an image gallery using HTML and CSS
* Implement image navigation using JavaScript
* Add next and previous button functionality
* Create a lightbox view for images
* Add hover effects and smooth transitions
* Ensure responsive design for different screen sizes
* Add image filters/categories (Bonus)

## 📱 Responsive Design

The gallery is optimized for:

* Desktop Devices
* Tablets
* Mobile Devices

## 🔍 Functionality

* Click any image to open it in a lightbox view.
* Navigate through images using the Next and Previous controls.
* Filter images based on categories.
* Enjoy smooth animations and hover effects for an enhanced user experience.

## 🧪 Testing

The project has been tested to ensure:

* Smooth image navigation
* Proper lightbox functionality
* Responsive layouts across devices
* Working category filters
* Consistent hover effects and transitions
* No layout overflow issues

## 📂 Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project folder:

   ```bash
   cd image-gallery
   ```

3. Open `index.html` in your browser or run it using a local development server.
